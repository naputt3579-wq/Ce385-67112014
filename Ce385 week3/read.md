# Workshop Ce385 week3

# ข้อ 1 ฟังก์ชันคำนวณคะแนน

สร้างฟังก์ชันสำหรับจัดการคะแนนของนักศึกษา โดยมีฟังก์ชันตรวจสอบคะแนน แปลงคะแนนเป็นเกรด คำนวณคะแนน Workshop และคำนวณคะแนนรวม

มีการใช้ Arrow Function และกำหนดค่าเริ่มต้นให้กับฟังก์ชันคำนวณคะแนน Workshop

ทดสอบข้อมูลนักศึกษา 3 คน และแสดงผลเป็นตาราง

# ข้อ 2 ทะเบียนนักศึกษา

สร้างข้อมูลนักศึกษาในรูปแบบ Array of Object จำนวน 6 คน โดยแต่ละคนมี id, name, major, score และ contact

สร้างฟังก์ชันสำหรับค้นหานักศึกษาจาก id ค้นหาตามสาขา ตรวจสอบว่ามีนักศึกษาที่คะแนนต่ำกว่า 50 และค้นหา email

มีการทดสอบกรณีค้นหาข้อมูลที่ไม่มีอยู่ และกรณีนักศึกษาไม่มีข้อมูล contact เพื่อให้โปรแกรมไม่เกิด error

---

## ข้อ 3 สรุปผลการเรียน

ใช้ข้อมูลนักศึกษาจากข้อ 2 มาสรุปผลการเรียน โดยใช้ map, filter และ reduce

สร้างฟังก์ชันสำหรับแสดงรายชื่อ หานักศึกษาที่สอบผ่าน หาคะแนนรวม คะแนนเฉลี่ย จำนวนคนตามเกรด และหานักศึกษาที่ได้คะแนนสูงสุด

นอกจากนี้ยังหาคะแนนเฉลี่ยของนักศึกษา CE ที่สอบผ่าน โดยใช้ filter, map และ reduce ต่อกัน

มีการทดสอบกรณี Array ว่างเพื่อให้ทุกฟังก์ชันสามารถทำงานได้โดยไม่เกิด error
