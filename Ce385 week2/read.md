 ข้อ 1 แนะนำตัว
สร้างตัวแปรเก็บข้อมูลส่วนตัว 5 อย่าง เช่น ชื่อเล่น รหัสนักศึกษา อายุ สาขาวิชา และจำนวนวิชาที่ลงทะเบียน
จากนั้นใช้ console.log()และ Template Literal เพื่อแสดงข้อมูลออกมาเป็นบัตรแนะนำตัว
นอกจากนี้ยังคำนวณปีที่จะจบจากปี 2569 และจำนวนปีที่เหลือ
ข้อ 2 — ชนิดข้อมูลและ typeof
สร้างตัวแปรให้ครบ 6 ชนิด ได้แก่ string, number, boolean, undefined, null array
ใช้ typeof เพื่อตรวจสอบชนิดของข้อมูลแต่ละตัว
ข้อ 3 — เครื่องคิดเลขคะแนน
สร้างตัวแปรเก็บคะแนนของแต่ละส่วน เช่น Workshop, Attendance, Project, Midterm และ Final
นำคะแนน Workshop มาคำนวณตามสูตรของวิชา แล้วนำคะแนนทั้งหมดมารวมกัน
จากนั้นคำนวณเปอร์เซ็นต์ และดูว่ายังขาดอีกกี่คะแนนถึง 80 คะแนน
ข้อ 4 — ตัดเกรดจากคะแนน
สร้างฟังก์ชัน toGrade(score) เพื่อเปลี่ยนคะแนนเป็นเกรดตามเกณฑ์ที่กำหนด
ใช้ if / else if ตรวจสอบคะแนนจากมากไปน้อย เช่น 80 ขึ้นไปได้ A และ 75 ขึ้นไปได้ B+
มีการตรวจสอบคะแนนที่ไม่อยู่ในช่วง 0-100 ก่อนตัดเกรด
จากนั้นสร้าง Array ของคะแนนหลายค่าและใช้ for...of เพื่อทดสอบทั้งหมด
 ข้อ 5 — ระบบสั่งอาหาร
สร้างฟังก์ชัน getMenuPrice(menu) เพื่อหาค่าอาหารแต่ละเมนูโดยใช้ switch
เมนูที่ราคา 50 บาทเหมือนกันจะใช้ fall-through รวม case เข้าด้วยกัน
สร้างฟังก์ชัน getSizeMultiplier(size) เพื่อกำหนดตัวคูณตามขนาดอาหาร
จากนั้นสร้าง Array ของออร์เดอร์ และคำนวณราคาของแต่ละรายการ รวมถึงราคารวมทั้งบิล
มีการใส่เมนูที่ไม่มีในรายการเพื่อทดสอบ default
สร้างฟังก์ชัน login()สำหรับตรวจสอบการเข้าสู่ระบบ
ตรวจสอบตามลำดับ คือ username/password → สถานะบัญชี → อายุ → role
ถ้าข้อมูลไม่ถูกต้องจะแสดงข้อความตามเงื่อนไข เช่น 401 หรือ 403
มีการทดสอบหลายกรณี เช่น เข้าสำเร็จ รหัสผ่านผิด ชื่อผู้ใช้ผิด บัญชีถูกระงับ และอายุไม่ถึงเกณฑ์
