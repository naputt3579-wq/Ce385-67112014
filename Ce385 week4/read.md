# Workshop 3

## ข้อ 1 Callback

ข้อนี้ทำระบบค้นหาข้อมูลนักศึกษาจาก id โดยใช้ Callback แบบ Error-first
ถ้าไม่พบข้อมูลหรือ id ไม่ถูกต้อง จะแสดง Error
ถ้าพบข้อมูลจะแสดงข้อมูลนักศึกษา โดยมีการใช้ setTimeout จำลองการทำงาน

## ข้อ 2 Promise

ข้อนี้เปลี่ยนจาก Callback มาใช้ Promise
ใช้ resolve เมื่อทำงานสำเร็จ และ reject เมื่อเกิด Error
จากนั้นใช้ then, catch และ finally ในการจัดการผลลัพธ์

## ข้อ 3 Async / Await

ข้อนี้นำ Promise มาใช้กับ async/await
มีการเปรียบเทียบการทำงานแบบทีละคนกับการทำงานพร้อมกันด้วย Promise.all
ผลคือ Promise.all ทำงานได้เร็วกว่า เพราะสามารถทำงานพร้อมกันได้

## ข้อ 4 Promise Combinators

ข้อนี้ฝึกใช้ Promise Combinator แต่ละแบบให้เหมาะกับงาน

- Promise.all ใช้เมื่อต้องการผลลัพธ์ครบทุกงาน
- Promise.allSettled ใช้เมื่อต้องการรู้ผลของทุกงาน
- Promise.any ใช้เมื่อต้องการตัวแรกที่สำเร็จ
- Promise.race ใช้เมื่อต้องการตัวที่เสร็จก่อน

ในแต่ละสถานการณ์มีการจัดการ Error เพื่อไม่ให้โปรแกรมหยุดทำงาน
